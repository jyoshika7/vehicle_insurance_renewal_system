# Vehicle Insurance Renewal System

## Project Description
The Vehicle Insurance Renewal System is a web-based application developed to help insurance agents manage customer details, vehicle information, policy expiry dates, and insurance renewals.
This is developed using PHP, MySQL, HTML, CSS, JavaScript and Bootstrap.

## Technologies Used
- Frontend: HTML, CSS, JavaScript, Bootstrap
- Backend: PHP
- Database: MySQL
- Local Server: XAMPP

## Main Features
- Agent Login and Dashboard
- Customer Management (Add, Edit, Delete)
- Vehicle and Insurance Policy Management
- Policy Expiry Status (Active, Expiring Soon, Expired)
- Insurance Renewal Management
- Renewal Notifications through Email
- Reports and PDF/Excel Export
- Search and Filter

## Installation Steps
1. Install XAMPP.
2. Copy the project folder into `C:\xampp\htdocs\`.
3. Start Apache and MySQL.
4. Open phpMyAdmin and create a database for the project.
5. Import the provided SQL file.
6. Update the database configuration file with your local MySQL settings.
7. Open `http://localhost/vehicle_insurance/login.php` in your browser.

## Project Purpose
This project was developed as an MCA mini project to simplify insurance policy tracking and renewal management.
